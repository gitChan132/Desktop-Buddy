# Handoff — desktop-buddy (The Feeling Frog)

Read this first, then continue from "Next up".

## What this is
Tauri v2 + React desktop frog companion. Rust daemons watch input timing and the foreground
window, then fire a `trigger-intervention` event → speech bubble above the frog. Copy is
generated by Gemini (`src-tauri/src/ai_engine.rs`); `GEMINI_API_KEY` comes from env or
`.env.local`, with deterministic fallback copy when the model/key is unavailable.

## Current state (Nov 2026)
- **All seven triggers work end-to-end** (real injected input + live Gemini), verified against
  the running app.
- 35 Rust unit tests pass; `tsc --noEmit` and `vite build` clean.
- Frontend includes the draggable frog with carry physics, the 10s speech bubble, and the
  guided breathing modal (shared `src/breathing.ts` rhythm: 3s in / 3s hold / 5s out).

### Triggers
| Trigger | Detection | Suggested action | e2e |
| --- | --- | --- | --- |
| `frantic_typing` | ≥180 keys / 30s | `belly_breathe` | ✅ |
| `backspace_loop` | ≥36 backspaces / 30s or streak ≥8 | `belly_breathe` | ✅ |
| `cursor_hesitation` | ≥3 clicks, each after ≥2s stillness / 30s | `belly_breathe` | ✅ |
| `cursor_oscillation` | ≥6 horizontal reversals / 10s | `belly_breathe` | ✅ |
| `tab_thrashing` | >8 window switches / 20s | `visual_grounding` | ✅ |
| `idle_freeze` | ≥150s zero input, browser/editor frontmost | `visual_grounding` | ✅ |
| `doomscroll` | feed frontmost ≥4 min, ≥40 scrolls / 90s, <10 keys / 30s | `visual_grounding` | ✅ |

Priority: backspace_loop → frantic_typing → cursor_hesitation → cursor_oscillation →
tab_thrashing → idle_freeze.

### Timers & thresholds
- Telemetry window 30s; stress score refreshed every 5s; cursor events throttled to 20 Hz.
- Backspace streak ends after 5s of no backspace. Thrash window 20s, polled every 2s.
- Idle freeze default **150s (2.5 min)**. Evaluation loop every **10s**. Intervention
  cooldown **45s per process** → one nudge per app run; restart between e2e tests.
- Stress weights: keys .25, backspaces .15, velocity .15, jitter .10, hesitation .15,
  oscillation .20.

## Dev / test hooks (remove or gate before ship)
- `FROG_FORCE_TRIGGER=<trigger>` → fires one intervention 2s after launch (`fire_forced`).
- `FROG_EVAL_SECS=<n>` → evaluation-loop cadence override.
- `FROG_IDLE_FREEZE_SECS=<n>` → idle-freeze threshold override.
- Debug `eprintln!` tick log (`keys/backspaces/streak/switches/thrash/idle/hesit/rev/stress`)
  and `[ai_engine] emitted trigger=...` — **temporary**.

## Test harness
- `cd src-tauri && cargo test --lib` — deterministic, zero-wait unit tests for scoring,
  detection thresholds, request building, severity bands.
- Injectors (pyobjc Quartz): `/tmp/inject_typing.py` (frantic), `/tmp/inject_hesitation.py`
  (click-after-stillness), `/tmp/inject_oscillation.py` (back-and-forth). Tab thrash: cycle
  `open -a Terminal/Safari/Finder`. Idle: focus Safari, no input.
- After tests: `pkill -f "tauri dev"; pkill -f desktop-buddy; pkill -f vite;
  lsof -ti tcp:1420 | xargs kill -9`.
